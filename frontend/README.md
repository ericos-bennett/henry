# Career Scraper Frontend

React + TypeScript (Vite) single-page app for the Career Scraper API. See the [root README](../README.md) for setup and the [architecture docs](../docs/architecture.md) for how this fits together with the backend.

```sh
npm install
npm run dev
```

Requires the backend running on `http://127.0.0.1:8000` — the dev server proxies `/api/*` there (see `vite.config.ts`).
